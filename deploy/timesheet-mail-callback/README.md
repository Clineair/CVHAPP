# Timesheet mail callback host

This folder is a deploy recipe for the standalone HTTPS callback in
`timesheet_mail_callback.py`. It is not started by the Streamlit app.

See `docs/TIMESHEET_AUTH.md` for the architecture, official provider limits,
verified hosting costs, and what still needs explicit approval before any
cloud project, billing account, OAuth app, secret, or test email is created.

Do not run a Cloud Run or other billed deploy from this recipe until that
approval is given.
